# Client Basic Requirements
## Animal Rescue Management System

The following user stories describe the basic requirements collected from the perspective of people who would use an Animal Rescue Management System. They are aligned with the current project modules and functionality.

### 1. Animal Management

**US-01 — Register an Animal**

As a rescue staff member, I want to add a new animal record with its name, species, age, health status, and description, so that the organization can keep track of every rescued animal.

**US-02 — Update Animal Information**

As a rescue staff member, I want to update an animal's information and health status, so that the records remain accurate and up to date.

**US-03 — View Animal Records**

As a rescue staff member, I want to view the list of registered animals and their details, so that I can easily monitor the animals under the organization's care.

**US-04 — Manage Adoption Availability**

As a rescue staff member, I want to update an animal's adoption availability, so that the organization knows which animals are ready for adoption.

### 2. Adopter Management

**US-05 — Register an Adopter**

As a rescue staff member, I want to register people interested in adopting animals and store their contact information, so that the organization can maintain an organized record of potential adopters.

**US-06 — Manage Adopter Records**

As a rescue staff member, I want to view, update, and delete adopter records, so that adopter information stays organized and accurate.

### 3. Donation Management

**US-07 — Record Donations**

As a donation manager, I want to record donations and their details, so that the organization can keep track of the support it receives.

**US-08 — Support Different Donation Types**

As a donation manager, I want to record online, cheque, and in-kind donations, so that the system can handle different forms of contributions.

**US-09 — Add Optional Donation Details**

As a donor or donation manager, I want to include recurring donation details or an "in memory of" dedication when applicable, so that donations can represent different donor preferences.

### 4. Volunteer Management

**US-10 — Register Volunteers**

As a volunteer coordinator, I want to add volunteer information, including contact details, skills, and availability, so that the organization can maintain a record of people willing to help.

**US-11 — Find Suitable Volunteers**

As a volunteer coordinator, I want to match volunteers according to their skills or availability, so that I can select suitable people for different rescue activities.

### 5. Rescue Event Management

**US-12 — Create and Manage Events**

As an event coordinator, I want to create and update rescue events, so that the organization can plan and manage its activities.

**US-13 — Register Volunteers for Events**

As an event coordinator, I want to register volunteers for specific events, so that I can keep track of who is participating in each activity.

### 6. Communication Management

**US-14 — Send Notifications Through Different Channels**

As a rescue staff member, I want to send communications through supported channels such as email, SMS, or social media posts, so that I can reach the intended recipients using an appropriate channel.

**US-15 — Receive Updates About Important Activities**

As a rescue coordinator, I want relevant observers to respond to important animal-status changes, donations, and event updates, so that I can stay informed about important activities in the organization.

### 7. User Management

**US-16 — Manage System Users**

As a system administrator, I want to manage user records, so that the organization can maintain its system users in an organized way.
